# Midnight Fare 剧本大纲

## 1. 项目定位

- 类型：分阶段对话叙事游戏
- 背景：虚构的 1990 年代都市，气质接近泡沫经济末期的日本夜景
- 主角：深夜出租车司机
- 核心玩法：
  - NPC 先连续说一段话
  - 玩家在短暂窗口内选择回应
  - 回应速度和态度会影响对话温度与信息释放
- 目标气质：
  - 深夜都市
  - 短暂同乘
  - 礼貌、体面、克制下的情绪裂缝
  - PG 向，不依赖失踪、暴力、犯罪冲击

---

## 2. 核心叙事概念

这不是一个“破案”故事，而是一个关于“错过的回应”的故事。

玩家在 Level 0 载到一位看似只是教程用的乘客。那段对话当时看起来只是系统教学，但随着后续三位乘客的讲述，玩家会逐渐意识到：

- Level 0 不是教程外壳
- 那一夜的那段车内对话，正是整部故事的起点
- 玩家不是全知旁观者，而是曾经亲历过关键瞬间的人

故事的重点不是“谁做了坏事”，而是：

**人们在午夜的短暂相遇里，说过什么、没说什么，以及这些沉默如何改变之后的人生。**

---

## 3. 故事主题

### 核心主题

1. 回应别人，会改变一个瞬间的重量
2. 深夜的陌生人，有时比熟人更接近真心
3. 真相不会从一个人嘴里完整说出，只会以碎片形式出现
4. 玩家以为自己只是“开车的人”，其实也曾走进别人的命运

### 次级主题

- 90 年代都市繁华表面下的空心感
- 体面语言之下的犹豫与疲惫
- “差一点”构成的人生
- 记忆的后知后觉

---

## 4. 整体结构

本作主线由四段构成：

1. Level 0：关键起点，伪装成教程
2. Level 1：补足那一夜之前的状态
3. Level 2：补足她为何会走到那个边缘
4. Level 3：补足那一夜之后的回响

注意：

- Level 1~3 的 NPC 都**不能知道 Level 0 车内对话的完整内容**
- 他们只能知道自己立场内合理知道的部分
- 最终“真相”不是谁直接说出来，而是玩家把四段拼起来得到的

---

## 5. 核心人物关系

### 玩家

- 深夜出租车司机
- 工作让他习惯听别人说话，但不习惯真正介入
- 以为自己只是载客的人
- 实际上曾在一个关键夜晚，短暂地走进过一位乘客的人生决定

### Level 0 NPC：雾岛 真由（暂定）

- 年轻女性
- 看似只是教程关 NPC
- 实际上是整部故事的中心人物
- 她并不神秘，也不是“系统人格”
- 她只是那个夜晚里，一个正在决定自己接下来人生方向的人

她的重要性在于：

- 只有玩家亲历过那段车内对话
- 当时玩家没意识到这段对话的分量
- 后面三关会让玩家重新理解她当时每一句话

---

## 6. Level 0 大纲：伪装成教程的起点

### 表层功能

- 教玩家系统规则
- 教玩家 NPC 先说、玩家后答
- 教玩家上下选择、空格确认、鼠标点击
- 教玩家不回应会造成负面反馈

### 真实剧情功能

- 建立真由的说话方式
- 让她先于所有正式关卡出场
- 留下若干看似普通、实则可回收的台词

### 真由此时的状态

- 她在去往某个地方的路上
- 她还没做出最终决定
- 她在试探眼前这个司机是不是会回应别人、会听别人把话说完的人

### Level 0 结束后玩家应有的感觉

- 表面：教程结束，学会机制
- 潜意识：这个 NPC 说话有点太像真人了

### Level 0 结尾的隐藏作用

它要让玩家在后面三关结束后回头意识到：

**真由不是教程的包装，她就是故事真正的第一位乘客。**

---

## 7. Level 1 大纲：她那晚“看起来”的样子

### NPC：早川 梓（暂定）

- 身份：真由的同事 / 旧友
- 气质：礼貌、克制、微微疲惫
- 表达方式：避重就轻，先讲表层事实，再慢慢露出情绪

### 她合理知道的内容

- 真由那天晚上情绪不对
- 真由原本答应过某件事，后来开始犹豫
- 真由那天一直像在等一个“最后的决定”
- 真由在那晚中途上了一辆出租车

### 她绝对不知道的内容

- 真由和司机具体说了什么
- 真由在车里有没有改变目的地
- 司机回应她的具体态度

### 这一关要提供的信息

1. 真由那晚不是普通地回家
2. 她在那之前已经处于动摇状态
3. 她身边的人看得出她不对劲，但没人真正问到底

### 这一关的主题词

- 回避
- 差一点问出口
- 礼貌掩盖担心

### 这一关结束时玩家的理解

玩家开始觉得：

**Level 0 那个教程 NPC，原来真的是这晚现实里的一位乘客。**

---

## 8. Level 2 大纲：她为什么会走到那个边缘

### NPC：藤堂 修（暂定）

- 身份：真由工作圈或生活圈里的年长男性
- 可选身份：
  - 上司
  - 客户方联系人
  - 家庭旧识
  - 牵涉她未来安排的人
- 气质：体面、自信、擅长包装
- 表达方式：先把一切讲得很合理，越往后越露出控制欲和自我辩护

### 他合理知道的内容

- 真由为什么长期被某种生活轨道困住
- 她身上承受了哪些期待
- 那晚她原本“应该”去哪里、做什么
- 她为什么突然不想照着别人安排走

### 他绝对不知道的内容

- 真由在出租车里是否向司机求助或试探
- 真由最后在车里真正做出的决定

### 这一关要提供的信息

1. 真由并不是突然任性，她是长期压抑后到了临界点
2. 那一晚对她来说不是普通一夜，而是“再不做决定就来不及”的节点
3. 她不是在躲某个危险事件，而是在决定自己要不要继续过别人的人生

### 这一关主题词

- 包装
- 控制
- 被安排的人生
- 体面下的窒息

### 这一关结束时玩家的理解

玩家会开始重新回想 Level 0：

**她那时不是随便聊天，她是在一个真正的边缘上说话。**

---

## 9. Level 3 大纲：那一夜之后发生了什么

### NPC：南 云雀（暂定）

- 身份：后来某个时间再次见过真由的人
- 可选身份：
  - 她搬去的新地方认识的人
  - 夜校同学
  - 夜班工作伙伴
  - 与她后来短暂结识的朋友
- 气质：安静、观察力强、说得少但准确
- 表达方式：不解释太多，但记得细节

### 她合理知道的内容

- 真由后来有没有真的离开原本生活轨道
- 真由有没有提过那个决定开始于一趟出租车
- 真由对那位司机有没有留下印象
- 真由后来如何评价那一晚

### 她绝对不知道的内容

- 车里逐字逐句的具体对话
- 玩家当时到底选了哪个选项

### 她这一关提供的信息

1. 真由后来确实做出了某种改变
2. 她记得那一晚的出租车，不是因为发生了戏剧性大事，而是因为那是她开始把话说出口的地方
3. 她曾提到：司机有没有回应，影响了那个瞬间对她来说是“只是路程”还是“一个真正的转折点”

### 这一关主题词

- 回响
- 记得
- 微小回应的余波

### 这一关结束时玩家的理解

玩家最终明白：

**Level 0 的意义，不在于自己救了谁，而在于自己确实在某个午夜里，成为了别人做决定时的见证者。**

---

## 10. 终局揭示方式

不要让任何一个 NPC 直接宣布真相。

正确做法是：

1. Level 1 给出真由那夜“外在状态”
2. Level 2 给出真由那夜“内在原因”
3. Level 3 给出真由那夜“后续回响”
4. 玩家自己回头理解 Level 0 的所有台词

### 终局理解

玩家会意识到：

- Level 0 不只是系统引导
- 真由那晚并不是来给玩家上课
- 她当时真的在和玩家说话
- 她在确认眼前这个人，会不会回应她

### 最终情绪落点

不是“大反转”，而是：

**原来我当时就在故事里。**

---

## 11. PG 方向的情绪控制

为了保持 PG，同时仍有后劲，整部故事不要依赖：

- 失踪
- 暴力
- 明确犯罪
- 死亡冲击

可以依赖的情绪驱动力是：

- 被安排的人生
- 没说出口的话
- 深夜里临时改变方向
- 陌生人的一句回应
- 迟来的理解

换句话说：

故事张力来自**关系与选择**，而不是事件强度。

---

## 12. 三关玩法风格区分建议

虽然都是对话关，但三位正式 NPC 应该有不同的“开口方式”。

### Level 1 NPC

- 吃温和、耐心、轻声的回应
- 太冒犯会闭嘴
- 太冷淡会只讲表面

### Level 2 NPC

- 吃顺着他说、让他自己讲漏的回应
- 正面对抗会让他更会装
- 玩家需要学会“让他说”

### Level 3 NPC

- 吃准确、克制、不乱插话的回应
- 她不需要被哄，只需要被认真听
- 沉默不一定坏，但冷漠会坏

---

## 13. 关键回收点清单

后续正式写台词时，建议在 Level 0 埋下以下可回收元素：

1. 真由反复确认玩家是否会回应
2. 真由对沉默特别敏感
3. 真由提到“改变方向”或“还来得及吗”之类的普通句子
4. 真由有一句看似只是教程提醒，实则像在问自己
5. 真由结尾那句“你准备好了”在通关后要获得双重含义

### 通关后重新理解

- 教学层含义：玩家学会游戏机制
- 故事层含义：真由在确认她自己有没有准备好跨出那一步

---

## 14. 可继续扩写的方向

后续正式写作时，可以继续细化：

1. 三位 NPC 的姓名、年龄、职业、说话节奏
2. 真由那晚具体在决定什么
3. 三位 NPC 和真由之间的真实关系
4. 每关的分支回应风格
5. 真由在 Level 0 的关键台词回收

---

## 15. 一句话版故事概述

**在一座虚构的 1990 年代深夜都市里，出租车司机接连载到三位乘客，从他们各自有限的视角中，慢慢重新理解一位曾在教程关短暂出现的年轻女性，以及那个午夜里一段被自己错当成普通路程的关键对话。**
